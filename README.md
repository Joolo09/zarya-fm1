# ZARYA — оригинальная прошивка и веб-редактор для M-VAVE FM-1

Не форк Felucca, SLOOP и других: звуковой движок, секвенсор, генератор, интерфейс и
редактор написаны с нуля. Для железа используется только официальный SDK M-VAVE
(`m-vave/fm1_open`) — он отвечает за загрузку, USB/Bluetooth и штатное обновление.

**Статус: исходники и симулятор работают; под само устройство НЕ собрано и НЕ прошивалось.
См. `docs/SAFETY_STATUS.md` — сейчас `NO-GO: DO NOT FLASH`.**

## Что есть

- **4 трека**: 3 синта (общий пул 8 голосов) + драм-машина.
- **Синт**: 4 оператора FM/PM, 8 алгоритмов, 8 форм волны на оператор (sine, tri, saw, square,
  half, double, fold, noise), обратная связь, резонансный фильтр LP/BP/HP с огибающей,
  LFO (5 форм, 5 целей), 4 макроса, glide, mono/legato, стерео-spread.
- **Драмы**: 8 синтезированных инструментов (kick, snare, hats, clap, tom, rim, bell).
- **Эффекты**: темпо-дилей, ревер, drive, DJ-фильтр, pump от бочки, лимитер.
- **Секвенсор**: 64 шага, 8 сцен, свинг, длина гейта, вероятность, рэтчеты, аккорды на шаг,
  запись вживую и пошагово, арпеджиатор, привязка к ладу.
- **Генератор**: по зерну/тональности/плотности/сложности; одно зерно даёт одну гармонию для
  баса, аккордов, арпеджио и мелодии. Детерминированный, с отменой.
- **33 пресета + 4 кита**, 32 пользовательских слота и 8 проектов во флеше (две копии каждой
  записи, переживает обрыв питания; чужой раздел не трогается без явного FORMAT).
- **Веб-редактор** (браузер, без установки): виртуальный FM-1 с настоящим кодом прошивки в
  WebAssembly, Sound Lab, секвенсор, Melody Lab, микшер, библиотека, бэкап, диагностика, Web MIDI.

## Запуск

```bash
make test
```

```bash
make wasm schema
```

```bash
cd web && npm install && npm run dev
```

Откройте http://localhost:5173 в Chrome или Edge. `npm test` — контрактные тесты редактора
против прошивки, `npm run build` — сборка в `web/dist`.

## Управление на устройстве

SELECT — трек · ALGORITHM — подстраница · KNOB 1–4 — четыре ручки на экране ·
PRESETS — выбор звука (на SEQ — курсор шага) · HOME/EDIT/ENV/LFO/FX/SCL/GLO/ARP/SEQ/SAVE — страницы ·
повторное EDIT/ENV — следующий оператор · GLO + белые клавиши 1–4 — mute, 5–12 — сцены ·
на SCL: SAVE — сгенерировать, REC — отменить · на SEQ: белые клавиши — шаги, OCT± — страница.

## Структура

`core/` ядро (C99, без libc и float) · `device/` черновик адаптера под SDK · `host/` тесты ·
`wasm/` оболочка симулятора · `web/` редактор · `docs/` факты о железе, протокол, безопасность.
